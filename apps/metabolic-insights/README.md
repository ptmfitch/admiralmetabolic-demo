# Metabolic Insights

**DEMO / SYNTHETIC · for enablement only**

Local walkthrough for a fictional CAD-7 weight-outcomes analysis. Subject ids are masked study numbers. Nothing here is a clinical record, and the screens are not for clinical use.

From the repository root:

```bash
pnpm install
pnpm dev:metabolic
```

The app serves on port 5173. `pnpm test:metabolic` runs the Vitest suite.
